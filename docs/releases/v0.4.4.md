# v0.4.4 — OpenCode 2.4.1 validation

Released 2026-11-23. Requires OpenCode CLI `>=2.0.26 <2.5.0`; the Desktop GUI
entrypoint requires OpenCode Desktop **2.3.0+** and is validated against 2.4.1.

## Fix

OpenCode **2.4.1** was published on 2026-11-23, during the 2.4.0
compatibility pass. The declared range already admitted it, and this release
records the real validation and builds against `@opencode/plugin@2.4.1`.

The 2.4.1 SDK diff from 2.4.0 is additive only:
`experimental.automation.create/list/delete`, plus the OpenTUI peer floor
returning to 0.8.0. `model.request`, `http.request`, the experimental
WebSocket hooks, `retry`, session events, storage, RPC, and the TUI/GUI
surfaces this plugin uses keep their signatures. No runtime code changed
between v0.4.3 and this release.

## Verification

- Published `@opencode/plugin` 2.4.0 → 2.4.1 declaration diff reviewed: three
  files, all additive automation/peer changes; no surface used here changed.
- `npm run lint`, `npm run typecheck`, `npm test`: **176 tests, 0 failures**
  on the real **2.4.1** CLI/TUI.
- Real OpenCode 2.4.1 fixture and TUI tests: packed plugin loads, `/offpeak
  status` works, a protected request sends **0** provider requests before the
  peak boundary and exactly **1** at it.
- The exact `#v0.4.4` Git-tag install loads server, TUI, and Desktop GUI
  entrypoints; 2.4.0 and 2.3.2 remain supported and tested.

## Install

```sh
opencode plugin add git+https://github.com/lutzkind/opencode-offpeak.git#v0.4.4
```

Desktop users must list the same tag in Desktop's own `opencode.json(c)` and
run Desktop 2.3.0 or newer.
