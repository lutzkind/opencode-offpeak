# v0.3.1 — OpenCode 2.3.2 compatibility

Released 2026-11-18.

## Highlights

- **Validated on OpenCode 2.3.2.** The live host runs 2.3.2 (2.3.1 and 2.3.2
  shipped on 2026-11-18). Both are inside the existing range
  `>=2.0.26 <2.4.0`, and every hook, RPC channel, storage call, and TUI surface
  this package uses keeps its 2.3.0 signature.
- **Background compaction is covered.** OpenCode 2.3.1 enables
  `compaction.background` by default. A background summary prepares the same
  `compaction` model request as a foreground compaction, so the pre-model hold
  and the outbound transport guard apply unchanged. A real OpenCode 2.3.2
  fixture test proves a compact request at peak produces zero provider
  requests and exactly one at the boundary.
- **Dependency currency.** `@opencode/plugin` is now `2.3.2`. The published
  declarations differ from 2.3.0 only in `experimental.generate` (video is
  server-only) and a `codemode` variant of `SessionIdleBackground`, neither of
  which this package uses.

## Compatibility

- Server/TUI: OpenCode `>=2.0.26 <2.4.0` (unchanged).
- Desktop GUI: OpenCode Desktop 2.3.0 or newer.
- Build dependency: `@opencode/plugin@2.3.2`.

## Install

Server/CLI:

```sh
opencode plugin add git+https://github.com/lutzkind/opencode-offpeak.git#v0.3.1
```

Desktop (its own `opencode.json(c)`):

```jsonc
{
  "plugins": ["git+https://github.com/lutzkind/opencode-offpeak.git#v0.3.1"]
}
```

No configuration change is required when upgrading from `v0.3.0`.
