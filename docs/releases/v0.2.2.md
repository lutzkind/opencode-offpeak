# opencode-offpeak v0.2.2

Restores the plugin on OpenCode 2.3.0 and keeps the peak-price guard unchanged.

## Compatibility

**OpenCode `>=2.0.26 <2.4.0`**, validated against the live **2.3.0** host and the
minimum **2.0.26** host.

The previous release declared `<2.3.0`. On 2.3.0 both entrypoints threw the
compatibility error before registering any hook or command, so peak-price
blocking was completely absent. The failure was the guard, not a removed plugin
API: `context.app.version` is still a string, `dist/tui` declarations are
byte-identical to 2.0.26, and every hook, RPC channel, storage call, and TUI
surface this package uses is unchanged.

OpenCode 2.3 only adds plugin surfaces: `session.fork`,
`experimental.model.resolve`, `experimental.idle`, artifacts, credentials,
session instructions, event type filters, and a deprecated `generate` alias for
`experimental.generate.text`. The plugin calls none of the new surfaces. It
defines no custom renderables, so the OpenTUI 0.7/0.8 changes do not apply.

One 2.3 SDK change is noted but not worked around: `rpc.call` no longer waits up
to five seconds for a Location that is still loading plugins. The `/offpeak`
command is provided by the TUI entrypoint and normal interactive use happens
after reconciliation, so no retry loop was added.

## Verified

- 135/135 deterministic tests on 2.3.0, including the packed-plugin real-TUI
  load and `/offpeak status`.
- The same packed-plugin TUI smoke test on the minimum **2.0.26** binary.
- Source typechecks against `@opencode/plugin@2.0.26` (pinned minimum) and a
  scratch `@opencode/plugin@2.3.0` install.
- Zero-paid-traffic headless fixture run on 2.3.0: **0 provider requests before
  the peak boundary**, exactly **1** at the boundary, same pre-titled session,
  exit 0.
- Live install: both server and TUI entrypoints active on 2.3.0; `/offpeak
  status` reports the live pricing state; production policies, providers, and
  the queue schema unchanged.

## Installation

```sh
opencode plugin add git+https://github.com/lutzkind/opencode-offpeak.git#v0.2.2
```

Requires OpenCode CLI v2 `>=2.0.26 <2.4.0` (validated on 2.0.26 and 2.3.0).
