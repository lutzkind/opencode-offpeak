# v0.3.2 — Desktop per-session switch

Released 2026-11-19.

## Highlights

- **Per-session switch in the Desktop settings page.** The Offpeak page now has
  the same two levels as the CLI: **Desktop protection** remains the persistent
  client default, and **Allow peak pricing in this session** writes the explicit
  per-session override — the same `opencode-offpeak/session-overrides-v1` entry
  as `/offpeak session off`, through the server that owns the routed session.
- **Waiting work is released on the spot.** Turning the session switch on
  permits verified peak-priced requests in that session and releases a request
  it already has waiting for off-peak. Turning it off returns the session to its
  client default. Neither default is written.
- **No confused state.** The switch reflects the explicit override only. A
  client default that already permits peak pricing is shown as the effective
  protection, not as a session grant.

## Compatibility

- Server/TUI: OpenCode `>=2.0.26 <2.4.0` (unchanged).
- Desktop GUI: OpenCode Desktop 2.3.0 or newer (unchanged).
- Build dependency: `@opencode/plugin@2.3.2` (unchanged).

## Install

Server/CLI:

```sh
opencode plugin add git+https://github.com/lutzkind/opencode-offpeak.git#v0.3.2
```

Desktop (its own `opencode.json(c)`):

```jsonc
{
  "plugins": ["git+https://github.com/lutzkind/opencode-offpeak.git#v0.3.2"]
}
```

No configuration change is required when upgrading from `v0.3.1`.
