# v0.4.3 — OpenCode 2.4.0 compatibility

Released 2026-11-23. Requires OpenCode CLI `>=2.0.26 <2.5.0`; the Desktop GUI
entrypoint requires OpenCode Desktop **2.3.0+** and is validated against 2.4.0.

## Fix

OpenCode **2.4.0** was published on 2026-11-23 and the package still declared
the verified ceiling `<2.4.0`. Both entrypoints therefore refused to initialize
on a 2.4.0 host with the explicit compatibility error; on the live Desktop
server that rejected the whole plugin, so peak-price protection was absent.

The verified server/TUI range is now `>=2.0.26 <2.5.0`, and the build
dependency is `@opencode/plugin@2.4.0`. No runtime behavior changed: 2.4.0
keeps `model.request`, `http.request`, the experimental WebSocket hooks,
`retry`, session events, storage, RPC, and `context.keymap.layer()` unchanged.
Its additions are background jobs (`job.list`), video generation, automations,
opt-in GUI icon declarations, and composer delivery modes. This plugin
registers no code-block renderer or other custom renderable, so the OpenTUI
0.9.4 renderer change does not apply.

## Verification

- Published `@opencode/plugin` 2.3.2 → 2.4.0 declaration diff reviewed: no
  change to any surface this plugin uses; only additive job/video/tool/GUI
  declarations and the OpenTUI peer floor changed.
- `npm run lint`, `npm run typecheck`, `npm test`: **175 tests, 0 failures**
  against the 2.4.0 SDK.
- Real OpenCode 2.4.0 fixture and TUI tests: packed plugin loads, `/offpeak
  status` works, a protected request sends **0** provider requests before the
  peak boundary and exactly **1** at it.
- OpenCode 2.4 restores asynchronous plugin loading. The TUI smoke test waits
  for the TUI plugin's real `stage=setup` completion before typing, rather than
  racing the first painted prompt; the plugin behavior is unchanged.
- The live Desktop 2.4.0 server reloads `#v0.4.3` with no plugin load warning,
  and the live `status`, `client`, and `pricing` RPCs respond.

## Install

```sh
opencode plugin add git+https://github.com/lutzkind/opencode-offpeak.git#v0.4.3
```

Desktop users must list the same tag in Desktop's own `opencode.json(c)` and
run Desktop 2.3.0 or newer.
