# v0.4.2 — Desktop GUI bundle in git-tag installs

Released 2026-11-23. Requires OpenCode CLI `>=2.0.26 <2.4.0`; the Desktop GUI
entrypoint requires OpenCode Desktop **2.3.0+** and is validated against 2.3.2.

## Fix

The documented `opencode plugin add git+https://github.com/lutzkind/opencode-offpeak.git#vX.Y.Z`
path installed the package without `dist/`, because that directory was
gitignored. Desktop's `exports["./gui-experimental"]` then resolved to a missing
`dist/gui-experimental.cjs`, so the settings page and `/offpeak` slash command
could not load even though the server/TUI sources worked through their `bun`
condition.

The built `dist/gui-experimental.cjs` is now committed as the single build
artifact in the repository. Server and TUI still load their `bun` source
entrypoints. CI rebuilds the bundle and runs
`git diff --exit-code -- dist/gui-experimental.cjs`, so the committed file
cannot drift from `src/`.

## Verification

- `npm run check`: lint, typecheck, **175 tests, 0 failures**.
- The committed bundle SHA-256 matches the release tarball's bundle
  (`94f514debf4d070ffa3bdec5a314e56c470e1fd2c0c08da38751547dd6e1ab1d` for the
  v0.4.2 source).
- A clean v0.4.2 git-tag install contains `dist/gui-experimental.cjs` and only
  the app-provided shared modules are required by the bundle.

## Install

```sh
opencode plugin add git+https://github.com/lutzkind/opencode-offpeak.git#v0.4.2
```

Desktop users must list the same tag in Desktop's own `opencode.json(c)` and
run Desktop 2.3.0 or newer.
