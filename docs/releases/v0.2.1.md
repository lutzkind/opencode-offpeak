# opencode-offpeak v0.2.1

Restores the plugin on OpenCode 2.2.6, keeps the peak-price guard intact, and stops
telling operators to upgrade a host that is already too new.

## Compatibility

**OpenCode `>=2.0.26 <2.3.0`**, validated against the live **2.2.6** host and the
minimum **2.0.26** host.

The previous release declared `<2.2.0`. On 2.2.6 both entrypoints threw the
compatibility error before registering any hook or command, so peak-price blocking
was completely absent. The failure was the guard, not a removed plugin API:
`context.app.version` is still a string on 2.2.6, and the hooks, RPC channel, and
TUI surfaces used by this package are unchanged. The plugin defines no custom
renderables, so the OpenTUI 0.7/0.8 changes do not apply.

OpenCode 2.2.3 moved managed-policy plugin control from `integration.use` to
`plugin.use`. That is an operator policy surface, not a plugin API break; this host
has no managed policy source and no `plugin.use: deny`, so it did not mask the
version failure.

## Fixed

- The compatibility error no longer says `Run \`opencode upgrade\``. Upgrading is
  what moved the host past the verified ceiling. The message now says to use a
  release inside the range or to update `opencode-offpeak` before using a newer
  host.
- The hard-coded compatibility tests accept `2.2.0` through `2.2.6` and reject the
  `2.3.0` ceiling, instead of asserting that `2.2.0` is unsupported.
- The test runner uses `--test-force-exit` so a completed suite cannot leave a
  lingering child process holding CI open.

## Verified

- 135/135 deterministic tests on 2.2.6 and on 2.0.26, including the packed-plugin
  real-TUI load and `/offpeak status` on both hosts.
- Source typechecks against both `@opencode/plugin@2.0.26` (the pinned minimum) and
  a scratch `@opencode/plugin@2.2.6` install.
- Zero-paid-traffic headless fixture run: **0 provider requests before the peak
  boundary**, exactly **1** at the boundary, same pre-titled session, exit 0.
- Live install: both server and TUI entrypoints active on 2.2.6; `/offpeak status`
  reports the live pricing state; production policies and providers unchanged.

## Installation

```sh
opencode plugin add git+https://github.com/lutzkind/opencode-offpeak.git#v0.2.1
```

Requires OpenCode CLI v2 `>=2.0.26 <2.3.0` (validated on 2.0.26 and 2.2.6).
